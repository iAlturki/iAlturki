# Profile logos

Original profile graphics and animation: **© 2026 iAlturki**, [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

The software marks are authentic artwork from iAlturki's own public repositories, resized for small UI slots without inventing replacements:

- MicMute: [assets/logo.png](https://github.com/iAlturki/MicMute/blob/main/assets/logo.png), rendered by the application's real tray-icon code.
- Instant Replay Fix: [assets/logo.png](https://github.com/iAlturki/Nvidia_Instant_Replay_Fix/blob/main/assets/logo.png), extracted from the native app icon.
- Look20: [assets/logo.svg](https://github.com/iAlturki/Look20/blob/main/assets/logo.svg), the original pixel eye.
- ytr-music: [assets/logo.png](https://github.com/iAlturki/ytr-music/blob/main/assets/logo.png), extracted from the native app icon.
- iAlturki website mark: [the original favicon](https://444005129.xyz/favicon.svg), the green pixel `i`.

The GitHub mark is GitHub's official [Octicons mark-github-24](https://github.com/primer/octicons/blob/main/icons/mark-github-24.svg), used to identify the GitHub destination of the Hire me button. It retains its separate [MIT license](GITHUB-OCTICONS-LICENSE.txt); the original button artwork license does not replace that license or grant rights to GitHub's trademarks.

Sources retrieved on 2026-10-13. Rebuild the small app-logo PNGs with `python tools/prepare_profile_logos.py <directory-containing-the-project-checkouts>` after installing Pillow and resvg-py.
